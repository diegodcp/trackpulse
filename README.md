# TrackPulse LLM Development Guide

TrackPulse is an unofficial community project and is not affiliated with, endorsed by, or sponsored by Formula 1, FIA, or any teams, drivers, or rights holders.

TrackPulse is a live Formula 1 second-screen app: an animated circuit-condition map for TV viewing. It will show global track temperature, wind, traffic, inferred grip evolution, dirty zones, tyre stress, rain influence, fast/slow corner behavior, and concise live messages such as: “T3 is becoming faster with the current tailwind.”
